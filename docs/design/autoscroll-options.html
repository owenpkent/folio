Folio auto-scroll controls: design options

Outcome: none of these shipped as drawn. Folio went with the corner play/pause button alone, small slower and faster buttons under it, and a right-click menu for size (no stop button, speed readout or expanding panel; Esc or the toolbar button stops). This page is kept as the record of the options weighed.

Six ways to lay out the on-screen auto-scroll controls. Each mock below is live: press Play, change speed, change size, then switch on "Narrow / short area" to see how it copes (the area becomes 440 by 300 pixels, like a small window with the sidebar open). Mocks use Folio's dark theme; page chrome uses okstudio-style. The mocks do not handle keyboard shortcuts, only focus and Enter or Space on buttons.

Failure modes found in review: the bar growing wider than the area at large sizes, clipping when the sidebar opens, the Size popup clipping in short windows, and menu arrow keys leaking to the viewer. Designs with no popup and no overflow are marked in the Pros lists.
